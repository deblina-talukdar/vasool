# Demo files

Self-contained HTML files. Download one and open it in a browser (Microsoft Edge recommended for the Indian English voice).

- vasool_whatsapp_simulation_dark.html: a dark WhatsApp-style chat between Vasool and a payer (Sharma Traders): reminder, split-payment reply, payment link, a recreated Razorpay test payment page and the summary. Has a speed slider and two voices. Press H to hide the voice panel and R to replay.
- vasool_24s_animated_story.html: a 24-second animated explainer of what Vasool does, with an Indian English voiceover (Microsoft Neerja if available).

All names, amounts and the payment page are fictional or test-mode. Browsers need a click before they will speak, so press Start.
